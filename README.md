# znuny-container
Znuny container image (unofficial)

Many thanks to https://github.com/effizienzwerk/docker-otrs

## Configuration
| Name | Description | Default value |
|----|-----|------|
| ZNUNY_FQDN | FQDN of the znuny application is reachable | |
| ZNUNY_HOSTNAME | Hostname of the znuny application container | |
| ZNUNY_DB_HOST | Database hostname | localhost |
| ZNUNY_DB_NAME | Database name | znuny |
| ZNUNY_DB_USER | Database username | |
| ZNUNY_DB_PASSWORD | Database password | |
